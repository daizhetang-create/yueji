# 约己 V0.3 发布与验收记录

发布日期：2026-08-24  
版本主题：共同约池机制演示、主动随记与自由安排

## 产品改动

- 共同约池采用“个人本金预计退回 / 约池贡献 / 共同奖励”三账展示；
- 网站与小程序均明确标记“机制演示”，当前不发生跨用户真实奖励转账；
- 任务可编辑名称、截止时间和每周出现日，并可创建自定义约定；
- 默认目标均为确定目标，“七天验证”降为添加页次级选项且不进入约池；
- 打卡完成后不自动弹反馈，用户主动点击“记一下”才打开星级与文字随记；
- 每个七日周期一次暂缓，只顺延一天、不降低目标次数；
- 服务端新增约池等份分配预览与余分冻结规则；
- CloudBase 增加随记、不可覆盖打卡事件、约池批次、约池明细和奖励付款预留结构。
