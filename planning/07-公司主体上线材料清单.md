# 约己：公司主体上线材料清单

## 原则

家里注册的公司可以作为约己的小程序和微信支付主体，但应取得公司法定代表人或有权管理员的明确同意。正式收款后的商户责任、退款、消费者投诉、发票、会计和税务均由该公司承担，不能仅“借用营业执照”。

不要把下列资料发到聊天、GitHub 或代码仓库。需要时由公司管理员在微信/腾讯官方页面直接填写。

## 公司管理员准备

- 有效营业执照和统一社会信用代码；
- 法定代表人或经授权经办人的身份证明与微信；
- 公司对公账户；微信官方允许的其他结算方式以申请页面为准；
- 可公开展示的客服电话；
- 与实际业务相符的经营范围、商户简称和服务说明；
- 一个从未注册过微信公众平台账号的邮箱；
- 拟作为小程序管理员的微信号；
- 公司内部对承诺金、退款、投诉与开票规则的书面确认。

## 现在就能做

1. 用游客 AppID 导入微信开发者工具，完成界面和交互验收。
2. 在个人腾讯云账号中建立仅用于开发的 CloudBase 测试环境。
3. 部署测试数据库与 `yueji-data` 云函数。
4. 用模拟支付验证三档定价、支付成功/取消/失败状态。
5. 测试七天结算、部分退款、重复回调和重复退款防护。
6. 准备小程序首页、服务页、支付规则页、隐私页和审核截图。
7. 准备用户协议、隐私政策、承诺金规则、申诉与客服流程草案。

测试环境不得存入公司支付私钥、APIv3 密钥或真实用户健康/支付数据。

## 公司参与后完成

1. 决定腾讯云生产账号归公司所有，或将当前个人腾讯云账号变更为企业实名认证。
2. 以公司主体注册并认证微信小程序，取得正式 AppID。
3. 申请微信支付商户号与小程序支付权限。
4. 将商户号与已认证小程序 AppID 绑定。
5. 在公司控制的 CloudBase 生产环境录入支付凭证。
6. 用小额真实订单测试支付、回调、对账和原路退款。
7. 公司确认协议、开票、税务和未退款金额的会计处理后，再开放给外部用户。

## 测试与生产必须分离

| 项目 | 测试环境 | 生产环境 |
|---|---|---|
| 归属 | 当前个人腾讯云账号可暂用 | 建议公司控制的腾讯云账号 |
| AppID | `touristappid` / 测试身份 | 公司认证的小程序 AppID |
| 支付 | 模拟，不收真钱 | 公司微信支付商户号 |
| 数据 | 虚构测试数据 | 真实用户数据，最小权限与备份 |
| 密钥 | 不存真实支付密钥 | 仅存 CloudBase 加密环境变量/集成中心 |
