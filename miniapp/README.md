# 约己微信小程序

1. 在微信公众平台注册并认证小程序，把 `project.config.example.json` 复制为 `project.config.json`，填入 AppID。
2. 在 `services/config.js` 填入已备案、已配置为小程序合法域名的 HTTPS 后端地址。
3. 使用微信开发者工具直接导入本目录。
4. 微信支付商户号与小程序 AppID 完成绑定后，在后端配置 `.env`，即可从「我的 → 微信支付」拉起真实收银台。

小程序首发使用「一次支付 7 天承诺金 → 服务端按完成记录结算 → 周期结束原路退回余额」；不把预约扣费伪装成可直接开通的通用自动扣款。
